# Player profile feature dictionary

## Source and scope

Generated by `Scripts/player_profile.py` from
`chess_performance_features_v2.csv`. Each row describes one player from 40
game-level records. The table is descriptive; it is not an ML training set and
does not define the final Player DNA vector.

The source's `accuracy` is a project-defined percentage of centipawn-evaluable
moves with CPL below 50. Mate-evaluation moves are excluded. CPL means
`max(0, best centipawn score - forced played-move centipawn score)`, and rows
involving mate scores are counted separately. The source exposes no opening,
middlegame, endgame, tactical motif, or positional evaluation breakdown.

“Candidate” means a reasonable behavior feature to evaluate later, not a final
selection. Outcome and rating fields are deliberately kept outside that
candidate set. If a later model predicts results for these same games, result
fields directly leak the target; profiles must be built from training-period
games only and evaluated on held-out games.

## Identifier, coverage, outcomes, and rating

| Column | Meaning and calculation | Unit / range | Use and caveat |
|---|---|---|---|
| `player_id` | Source player identifier. | Text ID | Join key; never a numeric feature. |
| `games_analyzed` | Number of source rows aggregated. | Games; exactly 40 here | Coverage / confidence context; not a style feature. |
| `wins` | Games where the player's color equals the recorded winner. | Count, 0–40 | Outcome descriptor; can leak a same-game result target. |
| `draws` | Games recorded as drawn. | Count, 0–40 | Outcome descriptor; same-game target leakage risk. |
| `losses` | Decisive games won by the opponent. | Count, 0–40 | Outcome descriptor; same-game target leakage risk. |
| `win_rate_pct` | Wins divided by games, ×100. | Percent, 0–100 | Outcome descriptor; exclude from style-only similarity. |
| `draw_rate_pct` | Draws divided by games, ×100. | Percent, 0–100 | Outcome descriptor; exclude from style-only similarity. |
| `loss_rate_pct` | Losses divided by games, ×100. | Percent, 0–100 | Outcome descriptor; exclude from style-only similarity. |
| `mean_player_rating` | Arithmetic mean of recorded player ratings. | Elo points | Strength context; can dominate style distance. |
| `median_player_rating` | Median recorded player rating. | Elo points | Robust strength context; redundant with mean rating. |
| `mean_opponent_rating` | Arithmetic mean of opponent ratings. | Elo points | Opponent-strength context; not a behavioral feature. |
| `median_opponent_rating` | Median opponent rating. | Elo points | Robust opponent-strength context; not a behavioral feature. |
| `mean_rating_difference` | Mean of player rating minus opponent rating, game by game. | Signed Elo points | Context for opponent strength; not a style feature. |

## Color and result performance

White/black result rates use the games played in that color as denominator.
`white_score_rate_pct` and `black_score_rate_pct` count a win as 1 point and
a draw as 0.5 points, divided by color games and multiplied by 100.

| Column | Meaning and calculation | Unit / range | Use and caveat |
|---|---|---|---|
| `games_as_white` | Number of games where the player was White. | Count, 0–40 | Exposure count; needed to interpret color splits. |
| `games_as_black` | Number of games where the player was Black. | Count, 0–40 | Exposure count; needed to interpret color splits. |
| `white_wins` | White games won by this player. | Count | Outcome descriptor; same-game target leakage risk. |
| `white_draws` | White games drawn. | Count | Outcome descriptor; same-game target leakage risk. |
| `white_losses` | White games lost by this player. | Count | Outcome descriptor; same-game target leakage risk. |
| `white_win_rate_pct` | White wins divided by White games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `white_draw_rate_pct` | White draws divided by White games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `white_loss_rate_pct` | White losses divided by White games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `white_score_rate_pct` | White score points (win=1, draw=0.5) per White game, ×100. | Percent, 0–100 | Color-specific results; sample-size sensitive. |
| `black_wins` | Black games won by this player. | Count | Outcome descriptor; same-game target leakage risk. |
| `black_draws` | Black games drawn. | Count | Outcome descriptor; same-game target leakage risk. |
| `black_losses` | Black games lost by this player. | Count | Outcome descriptor; same-game target leakage risk. |
| `black_win_rate_pct` | Black wins divided by Black games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `black_draw_rate_pct` | Black draws divided by Black games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `black_loss_rate_pct` | Black losses divided by Black games, ×100. | Percent, 0–100 | Color outcome descriptor; not core DNA. |
| `black_score_rate_pct` | Black score points (win=1, draw=0.5) per Black game, ×100. | Percent, 0–100 | Color-specific results; sample-size sensitive. |
| `white_mean_accuracy_pct` | Arithmetic mean source accuracy across White games. | Percent, 0–100 | Possible color-conditioned behavior feature; sample-size sensitive. |
| `black_mean_accuracy_pct` | Arithmetic mean source accuracy across Black games. | Percent, 0–100 | Possible color-conditioned behavior feature; sample-size sensitive. |
| `white_mean_cpl` | Mean game-level CPL across White games. | Centipawns, ≥0 | Possible color-conditioned quality feature; robust summaries preferred. |
| `black_mean_cpl` | Mean game-level CPL across Black games. | Centipawns, ≥0 | Possible color-conditioned quality feature; robust summaries preferred. |

If a player has no games in a color, that color's three performance averages,
score rate, and three outcome rates are intentionally blank (undefined). In
this cohort, two players have 40 White games and no Black games. The remaining
color-specific values also have unequal sample sizes, so avoid direct
color-style comparisons without uncertainty estimates.

|---|---|---|---|
| `mean_player_moves_per_game` | Mean of selected-player move counts across games. | Moves/game, ≥0 | Game-length context; influenced by termination and color. |

| `worst_game_accuracy_pct` | Minimum game-level accuracy. | Percent, 0–100 | Describes worst observed game; sensitive to outliers. |

## Centipawn loss and move quality

Means and standard deviations below summarize the 40 game-level values unless
the column explicitly says “weighted.” Standard deviation is sample SD
(`ddof=1`). CPL is nonnegative and excludes mate-evaluation moves at source.

| Column | Meaning and calculation | Unit / range | Use and caveat |
|---|---|---|---|
| `mean_cpl` | Arithmetic mean of game-level average CPL. | Centipawns, ≥0 | Candidate quality feature; sensitive to high-CPL games. |
| `median_cpl` | Median game-level average CPL. | Centipawns, ≥0 | Strong candidate robust quality feature. |
| `mean_cpl_weighted_by_cp_moves` | Mean game CPL weighted by that game's centipawn-evaluable move count. | Centipawns, ≥0 | Candidate move-weighted quality feature; avoids equal weight for unequal game lengths. |
| `cpl_std` | Sample SD of game-level average CPL. | Centipawns, ≥0 | Candidate consistency feature; sensitive to outliers. |
| `best_game_cpl` | Minimum game-level average CPL. | Centipawns, ≥0 | Best observed CPL game; sample-dependent. |
| `best_cpl_game_id` | ID of first source-order game attaining minimum CPL. | Text game ID | Audit reference only; never a model feature. |
| `worst_game_cpl` | Maximum game-level average CPL. | Centipawns, ≥0 | Worst observed CPL game; outlier-sensitive. |
| `worst_cpl_game_id` | ID of first source-order game attaining maximum CPL. | Text game ID | Audit reference only; never a model feature. |
| `mean_best_move_percentage` | Mean source near-best percentage across games. | Percent, 0–100 | Candidate behavior feature; source defines near-best as CPL ≤10. |
| `median_best_move_percentage` | Median source near-best percentage across games. | Percent, 0–100 | Robust candidate; redundant with mean best-move percentage. |

## Error rates and mate evaluations

The per-game error counts cover only centipawn-evaluable moves. The per-100
rates divide total move-class counts by total centipawn-evaluable moves and
multiply by 100. Mate-evaluation counts remain separate.

| Column | Meaning and calculation | Unit / range | Use and caveat |
|---|---|---|---|
| `mean_blunders_per_game` | Mean blunder count per game. | Blunders/game, ≥0 | Candidate behavior descriptor; length-sensitive. |
| `mean_mistakes_per_game` | Mean mistake count per game. | Mistakes/game, ≥0 | Candidate behavior descriptor; length-sensitive. |
| `mean_inaccuracies_per_game` | Mean inaccuracy count per game. | Inaccuracies/game, ≥0 | Candidate behavior descriptor; length-sensitive. |
| `blunders_per_100_cp_moves` | Total blunders / total CP-evaluable moves ×100. | Events/100 moves, 0–100 | Candidate normalized error-rate feature. |
| `mistakes_per_100_cp_moves` | Total mistakes / total CP-evaluable moves ×100. | Events/100 moves, 0–100 | Candidate normalized error-rate feature. |
| `inaccuracies_per_100_cp_moves` | Total inaccuracies / total CP-evaluable moves ×100. | Events/100 moves, 0–100 | Candidate normalized error-rate feature. |
| `cp_evaluable_moves_total` | Sum of source centipawn-comparable player moves. | Moves, >0 | Coverage / denominator; not a style feature. |
| `mate_evaluation_moves_total` | Sum of moves where either comparison returned a mate score. | Moves, ≥0 | Separate engine-event descriptor; candidate only after reliability review. |
| `mate_evaluation_rate_pct` | Mate-evaluation moves / all player moves ×100. | Percent, 0–100 | Context feature; depends on games reaching forced-mate positions. |
| `missed_forced_mates_total` | Count of mate evaluations classified as a missed forced win. | Events, ≥0 | Rare engine-event descriptor; not a stable core feature at 40 games. |
| `allowed_forced_mates_total` | Count classified as allowing a forced loss. | Events, ≥0 | Rare engine-event descriptor; not a stable core feature at 40 games. |
| `mate_score_changed_total` | Count of other mate-score changes between best and played searches. | Events, ≥0 | Engine-event descriptor; not ordinary CPL. |
| `mate_outcome_preserved_total` | Count where best and played mate distances match. | Events, ≥0 | Engine-event descriptor; not ordinary CPL. |

## Future feature-vector guidance

Reasonable initial candidates for later evaluation are `median_cpl`,
`mean_cpl_weighted_by_cp_moves`, `mean_accuracy_pct` or
`median_accuracy_pct` (choose carefully because they are related),
`accuracy_std_pct`, `cpl_std`, `mean_best_move_percentage`, and the three
per-100-CP-move error rates. Mate-evaluation rate and mate event counts should
remain exploratory until their stability is assessed on more games.

Do not include player/game IDs, outcome counts/rates, color outcome statistics,
ratings, or game IDs in a style-only vector. Ratings may be used separately as
a strength-compatibility constraint. Color-specific chess metrics may be
considered only with adequate per-color samples and normalization.

No opening-, middlegame-, endgame-, tactical-motif-, or positional-style
features are available in this profile. Those require additional position- or
move-level processing; they have not been fabricated here.
